# 사주 DB 형식

아래는 추출 단계에서 쓴 형식(v1)이고, 최종 `saju_db.json`은 여기에 다음이 더해졌다.

- 최상위: 레코드 7종 외에 `videos`(영상 id → 제목·업로드일), `meta`(건수·검수 상태 집계).
- `sources`: `"영상id@분:초"` 문자열 대신 `{"video": "영상id", "t": 초}` 객체 배열. 링크는 `https://youtu.be/{video}?t={t}`.
- 모든 레코드에 `id` (`K`개념 · `R`판단 규칙 · `P`궁합 · `T`운 · `S`절차 · `C`사례 · `E`표현).
- 개념: 같은 개념이 여러 이름으로 나오면 `aliases`, 다른 영상의 다른 설명은 `notes`.
- 규칙류(`rules`·`pair_rules`·`timing_rules`)에 검수 필드:
  - `merged_from`: 뜻이 같아 합친 원래 규칙 id 목록(1개면 합치지 않음). 개수가 곧 반복 언급 횟수.
  - `check`: `{"status": "표준일치|표준변형|채널독자|오류의심|판단불가", "note": "근거"}` — 일반 명리 이론과 대조한 결과. LLM 검수이며 전문가 감수가 아니다.
  - `related`: 조건이 같은데 해석이 엇갈리거나 함께 볼 규칙 id.

# 추출 형식 (v1)

출력은 JSON 객체 하나. 최상위 키 7개: `concepts`, `rules`, `pair_rules`, `timing_rules`, `procedures`, `cases`, `expressions`.
모든 문장은 한국어. **자막 원문을 옮기지 말고 뜻을 요약해 새로 쓴다**(한 항목 결론은 1~3문장). 근거는 `sources`에 `"영상id@분:초"` 문자열 배열로 단다(노트에 있는 위치 그대로).

## 이름 표기 규칙 (반드시 지킬 것)
- 천간: `갑(甲)` `을(乙)` `병(丙)` `정(丁)` `무(戊)` `기(己)` `경(庚)` `신(辛)` `임(壬)` `계(癸)`
- 지지: `자(子)` `축(丑)` `인(寅)` `묘(卯)` `진(辰)` `사(巳)` `오(午)` `미(未)` `신(申)` `유(酉)` `술(戌)` `해(亥)`
- 일주: `갑자(甲子)` 식 60갑자
- 오행: `목` `화` `토` `금` `수`
- 십성: `비견` `겁재` `식신` `상관` `편재` `정재` `편관` `정관` `편인` `정인`, 묶음은 `비겁` `식상` `재성` `관성` `인성`
- 자리: `연간` `연지` `월간` `월지` `일간` `일지` `시간` `시지`, 묶음 `연주` `월주` `일주자리` `시주`, `천간전체` `지지전체` `원국전체`
- 신살·관계: `도화` `홍염` `역마` `화개` `귀문` `원진` `공망` `양인` `백호` `괴강` `천을귀인` `천문성` … / `천간합` `삼합` `반합` `육합` `방합` `충` `형` `파` `해` `암합` `병존` `간여지동` `고립` `팔통`
- 화자: `초이` `모브` `라라` `최사주` `올리` `전문가(도화살편)` `게스트:이름` `불명`

## concepts — 개념별 채널 해석
```json
{"type": "천간|지지|일주|오행|십성|신살|관계|궁성|구조|운|용어",
 "name": "갑(甲)",
 "meaning": "이 채널이 말하는 핵심 의미 요약",
 "keywords": ["..."],
 "imagery": "물상·동물·캐릭터 비유 요약(없으면 빈 문자열)",
 "positive": "잘 발현될 때", "negative": "흑화·과할 때",
 "definitions": [{"variant": "표준|채널식|앱표시|게스트", "condition": "성립 조건", "speaker": "초이", "sources": ["..."]}],
 "speaker": "초이", "sources": ["..."]}
```
- 같은 개념이 노트에 여러 번 나오면 한 레코드로 합친다. 성립 조건이 학설별로 다르면 `definitions`에 여러 개.

## rules — 단일 사주 판단 규칙
```json
{"domain": ["성격|연애|결혼|직업|재물|건강|가족|인간관계|외모|개운"],
 "conditions": [{"axis": "...", "target": "...", "position": "...", "state": "...", "op": ">=", "value": 20}],
 "logic": "all|any",
 "condition_text": "사람이 읽는 조건 한 줄",
 "conclusion": "해석 요약",
 "polarity": "장점|흑화|중립",
 "prescription_self": "본인 처방(없으면 빈 문자열)",
 "prescription_other": "상대가 이 유형일 때 대하는 법(없으면 빈 문자열)",
 "confidence": "단정|경향|농담",
 "origin": "전통|채널임상|자작|오락|게스트",
 "correction": "보정켬|보정끔|무관|불명",
 "flags": ["시대의존", "성별버전", "표준과다름", "사실확인필요", "자막불확실", "안전주의"],
 "speaker": "초이", "sources": ["..."]}
```
- `axis` 값: `일간` `일주` `글자존재` `자리글자` `자리십성` `오행비율` `십성비율` `존재상태` `병존` `관계존재` `인접` `신강약` `신살` `계절` `음양` `구조`
- `state` 값(해당 시): `없음` `부족` `적정` `발달` `과다` `있음`
- 수치 기준이 있으면 `op`/`value`, 없으면 생략. 조건이 모호하면 flags에 넣지 말고 condition_text에 "(기준 모호)"라고 쓴다.
- `origin`: 일반 명리서에 있는 해석이면 전통, 화자가 "제 임상" 등으로 말하면 채널임상, "제가 지었다"·독자 이론이면 자작, 농담·오락 포맷이면 오락, 점다방 등 외부 게스트면 게스트.
- `flags.표준과다름`: 표준 명리 이론과 정의·관계가 다를 때. `사실확인필요`: 간지·절기 등 계산 사실이 틀렸을 가능성. `안전주의`: 투자·건강·성적·신점 단정.

## pair_rules — 궁합(두 사람) 규칙
```json
{"positions": "일지-일지|월주-일주|전체|…", "relation": "천간합|삼합|육합|충|형|원진|암합|오행보완|십성역할|같은일주|…",
 "condition_text": "...", "conclusion": "...", "effect": "끌림|지속|갈등|보완|중립",
 "asymmetric": false, "timing_condition": "만난 시점 운 조건(없으면 빈 문자열)",
 "confidence": "...", "origin": "...", "flags": [], "speaker": "...", "sources": []}
```

## timing_rules — 운(대운·세운·월운·삼재)
```json
{"layer": "대운|세운|월운|삼재|일반", "incoming": "들어오는 글자/오행/십성/신살",
 "natal_condition": "원국 조건(없으면 빈 문자열)", "conclusion": "...", "event_label": "연애운|이직|구설수|…",
 "prescription_self": "", "period": "특정 연도·월이면 기록(예: 2026 병오)",
 "confidence": "...", "origin": "...", "flags": [], "speaker": "...", "sources": []}
```

## procedures — 추론 절차
```json
{"kind": "단일사주|궁합|연예인풀이|월운|용신확정|원국뽑기", "steps": ["1단계 요약", "..."], "speaker": "...", "sources": []}
```

## cases — 사례 풀이
```json
{"subject": "공인 이름 또는 '시청자 A'(일반인은 익명)", "chart": "알려진 원국(모르면 빈 문자열, 시주 유무 명시)",
 "evidence": ["짚은 근거 글자·구조"], "conclusion": "...", "chart_certainty": "확실|추정|모름", "speaker": "...", "sources": []}
```

## expressions — 표현 자산
```json
{"kind": "비유|긍정재명명|면책|처방화법|고정화법", "target": "대상 개념(있으면)", "summary": "표현의 요지(원문 인용 금지, 요약)", "speaker": "...", "sources": []}
```
