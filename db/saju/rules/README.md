# 사주 DB (포스텔러 영상 해석 규칙)

포스텔러 FORCETELLER 유튜브 채널이 사주를 어떻게 읽는지 정리한 연구 자료입니다. 이 저장소의 기획 사례 DB(`db/cases.json`)와는 별개입니다.

- 웹에서 보기: `site/saju.html` (배포 https://360-degree-parallax.github.io/planning/saju.html)
- 데이터: [`saju_db.json`](saju_db.json) · 형식: [`SCHEMA.md`](SCHEMA.md)
- 만든 날: 2026-11-28

## 만든 방법

1. 2024-04-29 ~ 2026-11-23에 올라온 영상 179개의 YouTube 자막(176개가 자동 자막)을 이 컴퓨터에서 yt-dlp로 받았습니다.
2. 자막을 8묶음으로 나눠 끝까지 읽고, 추론 절차·개념·규칙·사례·화법을 관찰 노트로 정리했습니다. 타로·신점 영상은 뺐고, 실제로 규칙이 나온 영상은 143개입니다.
3. 노트를 `SCHEMA.md` 형식의 JSON으로 옮겼습니다. 자막 원문은 옮기지 않고 뜻만 요약했습니다.
4. 주제별 8묶음으로 나눠 뜻이 같은 규칙을 합쳤습니다. 이어서 규칙마다 일반 명리 이론과 대조해 `check`를 달았습니다. 간지·합충·12운성 같은 계산 사실은 직접 따져 봤습니다.

자막 원본과 중간 노트는 저작권 때문에 이 저장소에 넣지 않았습니다.

## 읽을 때 주의

- **채널 공식 자료가 아닙니다.** 자동 자막의 오기와 요약 과정의 오류가 있을 수 있습니다. 판단에 쓸 때는 `sources`의 시간 링크로 원본 영상을 확인하세요.
- **검수는 LLM이 한 것이고 명리 전문가 감수를 거치지 않았습니다.** '표준'은 자평진전·적천수·연해자평 계열의 일반 이론을 뜻하며, 학파마다 다른 부분이 있습니다.
- **농담·오락 규칙이 섞여 있습니다.** `confidence: 농담`, `origin: 오락`, `check.status: 판단불가`로 표시했고, 사이트에서는 숨길 수 있습니다.
- **안전 주의:** 투자·건강·성적 내용이나 신점을 단정한 규칙에는 `flags: 안전주의`가 붙어 있습니다.
- **화자 표시:** 화자는 자막만으로 구분해서 일부는 `불명`이거나 추정입니다.
- **사례의 원국:** 연예인 사례의 원국은 대부분 시주가 없고 자막에서 추정했습니다(`chart_certainty`).
- **유료 리포트에 쓸 때:** 채널 고유 해석(`채널독자`)을 서비스 문장으로 옮기지 않습니다. 구조와 관점만 참고하고 문장은 새로 써야 합니다.
