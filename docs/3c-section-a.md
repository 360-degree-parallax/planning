# 3C Section A 디깅: 니즈는 있는데 아직 아무도 들어가지 않은 영역

`db/cases.json`에서 생성(`tools/docs.py`). 3C 겹침에서 진입 칸으로 A를 고른 사례만 모았다.
A가 왜 아직 비어 있는지는 곧 **의심(Why not yet)**의 답이다. 그래서 사례마다 A 칸, Why not yet, So what 결론을 나란히 둔다.

- A: 고객 니즈는 있는데 아직 아무도 들어가지 않은 영역
- E: 현재 고객은 없지만 경쟁사와 우리가 싸우는 영역
- H: 아무도 아직 발견하지 못해 언제 G·A·F가 될지 알 수 없는 영역

## A를 진짜 A로 확인하는 질문

1. 니즈가 진짜인가: 고객이 지금 다른 방법(돈·시간·불편)으로 이 문제를 버티고 있나? 버티는 행동이 없으면 A가 아니라 H다.
2. 왜 아직 비었나(Why not yet): 통념, 강자의 수익원 충돌, 비고객이라 안 보임, 기술·제도가 막 열림, 작다고 무시, 신뢰 장치 부재 중 무엇인가?
3. 우리는 들어갈 수 있나: 들어가는 순간 A는 C(우리만 채움)가 된다. C로 만들 역량이 없으면 A는 그림의 떡이다.
4. 얼마나 버티나: 경쟁이 따라오면 C는 B·D가 된다. 따라오기 어렵게 만드는 장치(데이터, 네트워크, 규제, 원가)가 있나?

| 디자인 툴은 배우기 어렵다 (`canva`) | 누구나 쓰는 디자인 | 디자인은 디자이너가 하는 일이라는 통념 | 시장을 전문가에서 모두로 바꾸면 경쟁자가 사라진다 |
| 계약서 서명에 며칠 걸린다 (`docusign`) | 클릭으로 끝나는 서명 | 서명은 종이 한 장의 문제라는 통념. 실제로는 여러 사람의 흐름 관리였다 | 법·제도 변화의 순간에 오래된 불편을 없애라 |
| 오픈소스 코드 협업이 번거롭다 (`github`) | 사람이 협업하는 코드 | 개발자는 명령줄로 충분하다는 통념 | 기술 도구 위에 사람의 협업을 얹어라 |
| 회사 내부 사정을 알 수 없다 (`glassdoor`) | 재직자가 말하는 회사 | 회사 정보는 회사가 관리한다는 통념 | 주면 받는 구조로 민감한 데이터를 모아라 |
| 작은 회사의 급여·세금 처리가 어렵다 (`gusto`) | 모르는 사람도 쓰는 급여 | 급여는 전문가 영역이라는 통념 | 복잡한 업무를 모르는 사람도 쓰게 만들어라 |
| 신입이 3개월 안에 퇴사한다 (`hr-onboarding`) | 현실 그대로의 입사 경험 | 채용 때는 좋은 점만 보여야 한다는 통념 | 이탈은 들어오기 전 기대에서 시작된다 |
| 채용 공고가 흩어져 있다 (`indeed`) | 한곳에서 보는 모든 공고 | 채용 사이트는 공고를 직접 받아야 한다는 통념 | 흩어진 공급을 모으면 시작점이 된다 |
| 경력자를 채용하기 어렵다 (`linkedin`) | 구직 중이 아닌 인재에 닿기 | 이력서는 구직할 때만 쓴다는 통념 | 숨은 공급(수동적 구직자)을 드러내라 |
| 회의가 너무 많다 (`loom`) | 모이지 않는 설명 | 설명은 실시간이어야 한다는 통념 | 동시에라는 전제를 빼면 회의가 사라진다 |
| 작은 가게도 이메일 마케팅을 하고 싶다 (`mailchimp`) | 무료로 시작하는 이메일 마케팅 | 무료로 주면 돈을 못 번다는 통념. 그래서 유료 고객 기반이 충분할 때까지 기다렸다 | 작게 무료로 시작해 함께 자라라 |
| 업무 도구가 너무 많다 (`notion`) | 하나로 조립하는 업무 공간 | 도구는 한 가지 일을 잘해야 한다는 통념 | 사용자가 직접 조립하게 하면 하나로 여러 필요를 채운다 |
| 소상공인 POS가 폐업으로 해지된다 (`saas-churn-smb`) | 가게 매출을 돕는 POS | SaaS는 도구만 제공하면 된다는 통념 | B2B 리텐션의 본질은 고객 사업의 성공이다 |
| 온라인 스노보드 가게를 만들 도구가 없다 (`shopify`) | 누구나 여는 독립 가게 | 쇼핑몰은 개발 업체에 맡겨 만드는 것이라는 통념 | 상품이 아니라 가게를 여는 기술 장벽을 없애라 |
| 게임 회사가 망하기 직전이다 (`slack`) | 대화와 기록이 함께인 팀 채팅 | 업무 소통은 이메일이 표준이고 사내 메신저는 이미 많다는 통념 | 대화와 기록을 한곳에 두라 |
| 업무 앱끼리 연결이 안 된다 (`zapier`) | 코딩 없는 앱 연결 | 연동은 프로젝트로 판다는 통념 | 제품이 늘수록 그 사이를 잇는 제품의 가치가 커진다 |

| 한 번 입을 드레스가 너무 비싸다 (`rent-the-runway`) | 빌려 입는 고급 옷 | 옷은 빌려 입는 것이 아니라는 통념 | 한 번 입을 옷은 소유하지 말고 빌리게 하라 |
| 옷 밖으로 속옷 선이 보인다 (`spanx`) | 얇고 편한 보정 | 속옷 업계는 남성 중심 시각으로 설계 | 착용자가 직접 겪는 불편에서 출발하라 |
| 10대 패션 정보를 어디서 얻나 (`styleshare`) | 또래 코디와 바로 구매 | 패션 콘텐츠는 전문가가 만든다는 통념 | 전문가가 아니라 또래가 만든 콘텐츠로 팔아라 |
| 구독 해지가 3개월째에 몰린다 (`subscription-box`) | 내가 참여하는 구독 | 구독은 회사가 골라 주는 것이라는 통념 | 대신 골라 주되 고객이 참여하게 하라 |
| 안 입는 옷을 팔기 귀찮다 (`thredup`) | 봉투만 보내는 중고 판매 | 중고는 판매자가 직접 판다는 통념 | 판매자의 수고를 플랫폼이 대신하라 |
| 대형 할인점은 큰 도시에만 된다 (`walmart-rural`) | 소도시의 싼 쇼핑 | 소도시는 수요가 작다는 통념 때문에 경쟁자가 오지 않았다 | 남들이 작다고 본 시장을 먼저 독점하라 |
| 안경테가 너무 비싸다 (`warby-parker`) | 싼 안경을 집에서 써 보기 | 안경은 매장에서 써 봐야 한다는 통념 때문에 온라인 직판은 안 된다고 여겼다 | 써 보기를 매장에서 꺼내 집으로 보내라 |
| 여러 쇼핑몰을 돌아다니기 귀찮다 (`zigzag`) | 한곳에서 비교 | 소호몰은 각자 브랜드라 한곳에 모을 수 없다는 통념 | 흩어진 것을 모으기만 해도 시작점이 된다 |

### 플랫폼·모빌리티

| 사례 | A (빈 니즈) | 왜 아직 비었나 (Why not yet) | So what |
|---|---|---|---|
| 행사 기간 숙소 부족 (`airbnb`) | 현지스러운 싼 숙소 | 낯선 사람 집은 위험하다는 통념. 리뷰·프로필로 풀 수 있는 신뢰 문제였다 | 공급을 늘리려면 먼저 낯선 사람 사이의 신뢰를 설계하라 |
| 공항 수하물 대기 불만 (`baggage`) | 서서 기다리지 않기 | '대기 시간은 줄여야 한다'는 통념 때문에 시간을 일부러 늘리는 선택은 거꾸로라고 여겼다 | 처리를 빠르게 하지 말고 서 있는 시간을 걷는 시간으로 바꿔라 |
| 가게마다 배달 기사를 두기 어렵다 (`barogo`) | 함께 쓰는 배달 기사 | 배달은 가게 직원의 일이라는 통념 | 가게가 아니라 지역 단위로 수요를 모아라 |
| 장거리 이동이 비싸다 (`blablacar`) | 싼 장거리 이동 | 낯선 사람 차에 타는 건 위험하다는 통념 | 이미 달리는 빈자리를 신뢰로 연결하라 |
| 과외 매칭 앱에 선생님만 있고 학생이 없다 (`cold-start-marketplace`) | 검증된 동네 대학생 과외 | 광고로 수요를 모으면 된다는 통념 | 수요자 신뢰를 먼저 만들고 한 지역에 집중하라 |
| 배에 짐 싣고 내리는 데 며칠 걸린다 (`container`) | 싸고 빠른 운송 | 해운은 배의 문제라는 통념 때문에 항구-트럭-배를 하나의 시스템으로 보지 않았다 | 배가 아니라 화물의 모양을 표준화하라 |
| 동네 생활 정보를 찾기 어렵다 (`craigslist`) | 무료 지역 정보 | 광고는 돈을 받아야 사업이 된다는 통념 | 단순하고 무료인 게시판으로 비싼 지면을 대체하라 |
| 교외 지역은 음식 배달이 안 된다 (`doordash`) | 교외 배달 | 교외는 거리가 멀어 수익이 안 난다는 통념. 실제로는 주문 금액이 크고 주차가 쉬워 효율이 괜찮았다 | 경쟁자가 무시한 시장을 먼저 잡아라 |
| 낯선 사람과 경매 거래를 믿을 수 있을까 (`ebay-feedback`) | 낯선 사람 신뢰 | 신뢰는 기관이 보증해야 한다는 통념 | 신뢰를 이용자들이 나눠 만들게 하라 |
| 수공예품 팔 곳이 없다 (`etsy`) | 수공예 전용 장터 | 대형 장터가 모든 걸 다루니 전문 장터는 작다는 통념 | 정체성이 있는 전용 공간이 신뢰를 만든다 |
| 급한 서류를 다음 날 보낼 방법이 없다 (`fedex`) | 다음 날 보장 배송 | 직항이 가장 빠르다는 통념. 실제로는 한 곳에 모으는 게 연결 수를 줄인다 | 모든 화물을 한 허브로 모아 보장을 만들어라 |
| 국제 화물 운송이 깜깜이다 (`flexport`) | 한 화면에 보이는 화물 | 물류는 관계 영업 산업이라는 통념 | 흩어진 정보를 한 화면에 모아라 |
| 오토바이 택시 기사가 하루 대부분을 기다린다 (`gojek`) | 막히는 도시의 모든 심부름 | 오토바이 택시는 사람만 나른다는 통념 | 놀고 있는 네트워크 위에 서비스를 쌓아라 |
| 호텔 체크인 대기가 길다 (`hotel-checkin`) | 줄 없는 체크인 | 대기는 줄여야만 한다는 통념. 치과·엘리베이터처럼 채울 수도 있다 | 모두를 같은 줄에 세우지 마라 |
| 지하철역에서 마지막 1~2km가 애매하다 (`lime`) | 마지막 1~2km | 배터리·GPS·모바일 결제가 결합되며 가능해졌다 | 이동 수단은 규칙과 함께 풀어야 도시가 받아 준다 |
| 중고 명품 플랫폼에 매물이 부족하다 (`marketplace-liquidity`) | 수거해 가는 명품 판매 | 판매자가 직접 올려야 한다는 마켓플레이스 통념 | 공급이 부족하면 판매자의 수고를 대신하라 |
| 해외 현지 투어 정보를 믿을 수 없다 (`myrealtrip`) | 리뷰로 믿는 한국어 투어 | 투어는 여행사 상품이라는 통념 | 낯선 현지를 리뷰와 모국어 가이드로 믿게 하라 |
| 여행 갈 때 반려견을 맡길 곳이 없다 (`rover`) | 집 같은 반려견 돌봄 | 남에게 반려견을 맡기면 위험하다는 통념. 리뷰와 보험으로 풀 수 있었다 | 시설이 아니라 사람과 집을 연결하되 신뢰 장치를 붙여라 |
| 동네 전문가를 찾기 어렵다 (`soomgo`) | 요청 한 번에 견적 | 수수료는 거래 성사 때 받는다는 통념 | 고객이 찾지 말고 전문가가 찾아오게 하라 |
| 비행기 한 대를 팔아야 하는 항공사 (`southwest`) | 차만큼 싼 단거리 이동 | 업계는 회항 준비에 훨씬 긴 지상 시간이 필요하다고 당연하게 여겼다 | 싼 비행은 지상 시간을 줄이는 데서 나온다 |
| 승차 거부 없는 이동 (`tada`) | 거부 없는 조용한 이동 | 기사 재량 배차가 당연하다는 관행 때문에 안 했다 | 수요가 검증돼도 규제 위험을 풀지 못하면 사업이 멈춘다 |
| 택시를 잡을 수 없다 (`uber`) | 몇 분 안에 오는 차 | 요금은 고정이어야 공정하다는 통념 | 위치를 연결하고 공급을 풀어라 |
| 모텔은 숨어서 가는 곳 (`yanolja`) | 당당하게 비교하는 숙소 | 모텔은 정보를 숨기는 업종이라는 통념 | 숨겨진 정보를 공개하면 카테고리가 바뀐다 |
| 외딴 병원에 혈액이 제때 없다 (`zipline`) | 30분 내 혈액 | 드론 기술과 정부의 협력 의지가 맞아떨어졌다 | 쌓아 둘 수 없으면 필요할 때 빠르게 보내라 |

### 핀테크·금융

| 사례 | A (빈 니즈) | 왜 아직 비었나 (Why not yet) | So what |
|---|---|---|---|
| 내 돈이 어디 있는지 모른다 (`banksalad`) | 한 화면 자산 관리 | 금융 상품은 금융사가 파는 것이라는 통념 | 흩어진 정보를 모으면 판단이 생긴다 |
| 신용점수를 확인하려면 돈을 내야 한다 (`credit-karma`) | 공짜 신용점수 | 정보는 팔아야 돈이 된다는 통념 | 정보를 무료로 주고 추천에서 벌어라 |

| 케냐에서 송금하기가 어렵다 (`mpesa`) | 휴대폰 송금 | 금융은 은행이 하는 일이라는 통념 | 은행 대신 이미 있는 휴대폰과 동네 가게로 돈을 보내라 |
| 온라인 경매 대금을 주고받기 어렵다 (`paypal`) | 이메일로 받는 돈 | 처음엔 휴대기기 간 송금을 만들었지만, 실제 사용자는 경매 판매자였다. 원래 계획에 매달리는 통념을 버렸다 | 개인을 가맹점으로 만들어라 |
| 소액 결제에 현금이 부족하다 (`paytm`) | 단말기 없는 결제 | 결제는 단말기가 필요하다는 통념 | 위기의 순간에 가장 단순한 수단을 깔아라 |
| 주식 거래 수수료가 부담된다 (`robinhood`) | 수수료 없는 주식 | 증권사는 거래 수수료로 번다는 통념 | 수수료를 없애 새 투자자를 시장에 들여라 |
| 사회초년생이 저축을 못 한다 (`savings-goal`) | 월급날 먼저 떼는 저축 | 저축은 의지의 문제라는 통념 | 저축을 소비 앞에 두어라 |
| 작은 가게는 카드 결제를 받을 수 없다 (`square`) | 쉬운 카드 결제 | 소상공인은 위험해서 심사를 엄격히 해야 한다는 업계 통념 | 단말기보다 가입과 계약의 문턱을 없애라 |

| 복사기가 너무 비싸서 안 팔린다 (`xerox-914`) | 쓰는 만큼 내는 복사 | 장비는 팔아야 한다는 통념 | 장비가 아니라 사용을 팔아라 |

### 헬스케어

## A를 봤지만 실패한 사례 10건

A가 맞아도 C로 만들지 못하면 실패한다. 니즈 검증, 단위 경제, 안전 장치 중 무엇이 빠졌는지 본다.

| 사례 | A (빈 니즈) | 왜 실패했나 |
|---|---|---|
| 음성 소셜이 폭발적으로 컸다 (`clubhouse`) | 일상에서도 들을 이유 | 지속 이유라는 빈칸을 못 채웠다 |
| 짧은 고급 드라마를 모바일로 (`quibi`) | 돈 낼 이유 있는 짧은 영상 | 무료와의 차이를 못 만들었다 |
| 스마트폰 시장을 지배하고 있다 (`blackberry`) | 소비자용 안전한 스마트폰 | 소비자라는 새 칸을 놓쳤다 |
| 집에서 착즙 주스를 쉽게 (`juicero`) | 기계가 필요한 문제 | 실제로는 고객이 없는 G(자사만)에 서 있었다, 손보다 나은 A가 있는지 검증부터 했어야 한다 |
| 피 한 방울로 수백 가지 검사 (`theranos`) | 채혈 없는 검사 | 진짜 니즈(A)는 있었지만 C를 만들 기술이 없었다 |
| 세계에서 가장 싼 차 (`tata-nano`) | 자랑할 수 있는 첫 차 | 진입할 칸은 '자랑할 첫 차'였는데 '가장 싼 차'로 섰다 |
| 공동구매 할인이 폭발적으로 성장했다 (`groupon`) | 가게에 이익 되는 홍보 | 가게 이익이라는 A 칸을 못 채웠다 |
| 식료품 온라인 배송을 대규모로 (`webvan`) | 장보기 대행 | 칸은 맞았지만 수요보다 큰 설비 |
| 반려동물 용품 온라인 판매 (`pets-com`) | 정기배송 펫 쇼핑 | 정기배송으로 묶는 A 칸을 놓쳤다 |
| 익명 동네 게시판이 급성장했다 (`yikyak`) | 안전한 익명 게시판 | 안전이라는 A 칸을 못 채웠다 |
