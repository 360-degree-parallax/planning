## `dental` 치과 대기 경험

**우리 아이디어**: 결제 직후 리포트가 생성되는 대기 시간을 비워 두지 않는다. 예상 완료 시간과 진행 단계(명식 계산 → 대운 분석 → 문장 작성)를 보여 주고, 완성되면 메시지로 알려 열람률을 지킨다

**적합성 — 바꿔서** (문제 구조: 비슷함)

- 통한 이유: 할 일 없는 기다림은 실제보다 길게 느껴지고 불안을 키운다 → 예측 가능하고 쓸모 있게 만들면 불만이 준다
- 조건: 결과 생성 대기가 체감될 만큼 길다 → **모름**
- 조건: 대기 중 이탈·환불 문의가 있다 → **모름**
- 조건: 대기 화면에 보여 줄 내용이 있다 → **있음**
- 결정적 차이: 대기가 수 초라면 원인 자체가 없다

**Why not yet — 뻔함·기본기** (장벽: competition)

생성 대기 중 진행 단계를 보여 주는 것은 흔한 화면 설계라 차별점이 되기 어렵다. 경쟁사 적용 여부는 직접 확인 필요


## `elevator` 느린 엘리베이터

**우리 아이디어**: 거울처럼 '나'를 비춘다: 스토리 1p의 주인공을 방문자의 띠·오행 캐릭터로 바꿔 '내 이야기'로 느끼게 한다

**적합성 — 바꿔서** (문제 구조: 비슷함)

- 통한 이유: 지루한 시간에 '나'를 볼 거리를 주면 기다림이 덜 느껴진다
- 조건: 1p에서 이탈하는 이유가 지루함이다 → **모름**
- 조건: 생년월일 없이도 띠·오행 같은 개인 단서를 1p에 줄 수 있다 → **없음**
- 조건: 개인화 이미지 원가가 감당된다 → **모름**
- 결정적 차이: 1p 이전에는 생년월일이 없어 개인화가 불가능하다. 입력 위치를 1p 앞으로 옮기거나 유입 키워드로 대체해야 한다

**Why not yet — 타이밍·차별** (장벽: tech_change)

띠·오행별로 1p 주인공을 따로 그리면 제작비가 조합 수만큼 늘어 웹툰형 서비스도 공통 캐릭터를 쓰는 편이었다. 이미지 생성 원가가 내려가며 가능해졌다

- 근거 경쟁사: cheongwoldang
- 확인할 규정: birth-data-privacy

## `baggage` 공항 수하물 대기 불만

**우리 아이디어**: 결제 후 기다리는 몇 초를 '서서 기다리는 시간'이 아니라 '걷는 시간'으로: 로딩 대신 분석 과정을 순서대로 보여 주는 연출로 체감 대기를 줄이고 열람 이탈을 막는다

**적합성 — 바꿔서** (문제 구조: 비슷함)

- 통한 이유: 서서 기다리는 시간을 움직이는 시간으로 바꾸면 체감 대기가 준다
- 조건: 결과 생성에 체감 대기가 있다 → **모름**
- 조건: 대기 중 보여 줄 진행 과정이 실제로 있다 → **있음**
- 결정적 차이: 물리적 이동이 아닌 화면 연출로 바꿔야 한다

**Why not yet — 뻔함·기본기** (장벽: competition)

분석 과정을 연출하는 대기 화면은 흔한 장치다


## `disney` 놀이공원 긴 줄

**우리 아이디어**: 결제 전 두 페이지를 '통로'가 아니라 '무대'로: 1p 마지막 컷을 클리프행어(결정적 장면 직전)로 끝내 2p로 넘어가게 만든다

**적합성 — 바꿔서** (문제 구조: 비슷함)

- 통한 이유: 줄 서기를 체험의 일부로 만들면 기다림이 콘텐츠가 된다
- 조건: 1p·2p가 '거쳐야 하는 관문'으로 느껴진다 → **모름**
- 조건: 웹툰 연출 역량이 있다 → **있음**
- 결정적 차이: 놀이공원은 이미 표를 산 사람이 기다리지만 우리 방문자는 아직 사지 않았다. 체험이 결제 의사로 이어지는지 따로 봐야 한다

**Why not yet — 뻔함·기본기** (장벽: competition)

클리프행어로 다음 화면을 넘기게 하는 것은 웹툰 연출의 기본 문법이라 웹툰형 경쟁사도 쓴다

- 근거 경쟁사: cheongwoldang

## `cold` 아이가 비를 맞고 감기에 걸렸다

**우리 아이디어**: 환불·불만이 반복되면 '왜'를 거듭 물어 근본 원인을 찾는다: '해석이 틀렸다'인지 '2p에서 약속한 내용과 달랐다'인지 구분한다

**적합성 — 그대로** (문제 구조: 같음)

- 통한 이유: 겉 증상(감기) 대신 원인(비 맞음)을 다시 정의하면 해법이 단순해진다
- 조건: 환불·불만 사유를 기록하고 있다 → **모름**
- 조건: 사유를 원인별로 나눌 수 있을 만큼 건수가 있다 → **모름**
- 결정적 차이: 방법론이라 업종 차이가 작다

**Why not yet — 뻔함·기본기** (장벽: not_core)

환불 사유 분류는 운영 기본기다. 경쟁 우위가 아니라 빠뜨리면 안 되는 일


## `mri` 아이들이 MRI를 무서워한다

**우리 아이디어**: 불안한 고민(이별·실직)을 겁주는 경고로 시작하지 말고 극복 서사로 시작한다: 1p 웹툰이 '나도 그랬는데 길이 보였다'는 흐름이면 불안한 방문자도 끝까지 본다

**적합성 — 그대로** (문제 구조: 같음)

- 통한 이유: 무서운 경험을 '내가 주인공인 이야기'로 바꾸면 두려움이 줄고 끝까지 간다
- 조건: 불안한 고민(이별·실직)으로 들어오는 방문자가 많다 → **모름**
- 조건: 스토리형 1p가 있다 → **있음**
- 조건: 경고형 문구가 이탈을 부른다 → **모름**
- 결정적 차이: 아이 대상 의료 경험과 성인 대상 상업 콘텐츠라 '보호'가 아닌 '설득' 맥락이다

**Why not yet — 맹점·차별** (장벽: belief)

운세 광고는 '올해 조심해야 할 것'처럼 불안을 자극하는 경고형이 클릭을 더 부른다는 관행에 기대 왔다. 불안한 방문자가 끝까지 보는 것은 오히려 극복 서사일 수 있다

- 확인할 규정: false-discount-scarcity

## `embrace` 저렴한 인큐베이터 만들기

**우리 아이디어**: 과제를 그대로 받지 말고 실제 이용 장면을 본다: 방문자가 언제·어디서(새벽 침대, 출근길) 들어오는지 보고 광고 소재와 1p 첫 컷을 그 장면에 맞춘다

- 조건: 유입 시간대·상황 데이터가 있다 → **모름**
- 조건: 시간대별로 반응이 다르다 → **모름**
- 결정적 차이: 관찰 대상이 현장이 아닌 로그 데이터다

**Why not yet — 뻔함·기본기** (장벽: competition)

시간대·상황별 광고 소재 운영은 퍼포먼스 마케팅의 기본기다


## `airbnb` 행사 기간 숙소 부족

**우리 아이디어**: 낯선 서비스를 믿게 만드는 장치를 2p에: 실제 구매자 후기, 적중 사례, 리포트를 쓴 캐릭터·작가 프로필을 마케팅 페이지에 둔다

**적합성 — 바꿔서** (문제 구조: 비슷함)

- 통한 이유: 낯선 거래의 위험을 리뷰·프로필 같은 신뢰 장치가 덜어 준다
- 조건: 방문자가 '이게 맞을까'를 의심한다 → **있음**
- 조건: 실제 구매자 후기를 모을 수 있다 → **모름**
- 조건: 후기를 규정대로 표시할 수 있다 → **있음**
- 결정적 차이: 숙박은 물리적 위험, 사주는 '정확도'에 대한 의심이다. 후기의 내용이 적중·만족이어야 한다

**Why not yet — 뻔함·기본기** (장벽: competition)

후기 노출은 대부분의 서비스가 쓴다. 차별은 후기의 형식(적중 사례·작가 프로필)에서 나온다

- 확인할 규정: fake-reviews

## `netflix` 비디오 대여 연체료 불만

**우리 아이디어**: 압박·벌로 돈을 벌지 않는다: 가짜 카운트다운, 숨은 자동 결제 같은 장치는 당장 결제를 늘려도 환불·불신을 키운다. 가격과 포함 내용을 명확히 보여 준다

**적합성 — 바꿔서** (문제 구조: 다름)

- 통한 이유: 처벌(연체료)을 없애면 고객의 반감이 사라지고 이용이 는다
- 조건: 우리에게 처벌형 장치(카운트다운·압박 문구)가 있다 → **모름**
- 조건: 압박 장치가 환불·불신을 부른다 → **모름**
- 결정적 차이: 넷플릭스는 이용 중 처벌, 우리는 구매 전 압박이다. 옮기는 것은 '압박을 매출 수단으로 쓰지 않는다'는 원칙뿐

**Why not yet — 타이밍·기본기** (장벽: regulation_change)

카운트다운·압박 문구는 실험에서 전환을 올린다는 이유로 유지돼 왔지만, 2025년 다크패턴 직접 규제로 제거가 선택이 아닌 필수가 됐다

- 확인할 규정: false-discount-scarcity, dark-sequential-price

## `dyson` 청소기 흡입력 저하

**우리 아이디어**: 경쟁사가 주제별로 쪼개 파는 동안 '한 번 결제로 전체 결과 공개'가 우리 강점이다: 2p에서 포함 내용(연애·재물·건강·대운 등)을 전부 보여 주고 추가 결제 없음을 강조한다

**적합성 — 바꿔서** (문제 구조: 비슷함)

- 통한 이유: '쓸수록 나빠지는' 구조를 없애는 것이 성능 경쟁보다 강한 차별점이다
- 조건: 경쟁사가 주제를 쪼개 따로 판다 → **있음**
- 조건: 우리는 한 번 결제로 전부 연다 → **있음**
- 조건: 고객이 쪼개 팔기에 불만이 있다 → **모름**
