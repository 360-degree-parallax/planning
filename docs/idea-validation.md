## `dental` 치과 대기 경험

**우리 아이디어**: 결제 직후 리포트가 생성되는 대기 시간을 비워 두지 않는다. 예상 완료 시간과 진행 단계(명식 계산 → 대운 분석 → 문장 작성)를 보여 주고, 완성되면 메시지로 알려 열람률을 지킨다

**적합성 — 바꿔서** (문제 구조: 비슷함)

- 통한 이유: 할 일 없는 기다림은 실제보다 길게 느껴지고 불안을 키운다 → 예측 가능하고 쓸모 있게 만들면 불만이 준다
- 조건: 결과 생성 대기가 체감될 만큼 길다 → **모름**
- 조건: 대기 중 이탈·환불 문의가 있다 → **모름**
- 조건: 대기 화면에 보여 줄 내용이 있다 → **있음**
- 결정적 차이: 대기가 수 초라면 원인 자체가 없다

**Why not yet — 뻔함·기본기** (장벽: competition)

생성 대기 중 진행 단계를 보여 주는 것은 흔한 화면 설계라 차별점이 되기 어렵다. 경쟁사 적용 여부는 직접 확인 필요

**적합성 — 바꿔서** (문제 구조: 비슷함)

- 통한 이유: 지루한 시간에 '나'를 볼 거리를 주면 기다림이 덜 느껴진다
- 조건: 1p에서 이탈하는 이유가 지루함이다 → **모름**
- 조건: 생년월일 없이도 띠·오행 같은 개인 단서를 1p에 줄 수 있다 → **없음**
- 조건: 개인화 이미지 원가가 감당된다 → **모름**
- 결정적 차이: 1p 이전에는 생년월일이 없어 개인화가 불가능하다. 입력 위치를 1p 앞으로 옮기거나 유입 키워드로 대체해야 한다

**Why not yet — 타이밍·차별** (장벽: tech_change)

띠·오행별로 1p 주인공을 따로 그리면 제작비가 조합 수만큼 늘어 웹툰형 서비스도 공통 캐릭터를 쓰는 편이었다. 이미지 생성 원가가 내려가며 가능해졌다

- 근거 경쟁사: cheongwoldang
- 확인할 규정: birth-data-privacy

- 통한 이유: 줄 서기를 체험의 일부로 만들면 기다림이 콘텐츠가 된다

**적합성 — 그대로** (문제 구조: 같음)

- 통한 이유: 무서운 경험을 '내가 주인공인 이야기'로 바꾸면 두려움이 줄고 끝까지 간다
- 조건: 불안한 고민(이별·실직)으로 들어오는 방문자가 많다 → **모름**

- 결정적 차이: 아이 대상 의료 경험과 성인 대상 상업 콘텐츠라 '보호'가 아닌 '설득' 맥락이다

**Why not yet — 맹점·차별** (장벽: belief)

운세 광고는 '올해 조심해야 할 것'처럼 불안을 자극하는 경고형이 클릭을 더 부른다는 관행에 기대 왔다. 불안한 방문자가 끝까지 보는 것은 오히려 극복 서사일 수 있다
