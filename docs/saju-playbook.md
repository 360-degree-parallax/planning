### 스토리 후킹 (1p) (`hook_story`) — 사례 41개

살아남은 가설의 주요 장벽: 업계·고객 통념 33, 기술 변화 13, 문제·고객 정의 11

**느린 엘리베이터** (`elevator`)
- 적용: 거울처럼 '나'를 비춘다: 스토리 1p의 주인공을 방문자의 띠·오행 캐릭터로 바꿔 '내 이야기'로 느끼게 한다
- 실험: 1p 주인공을 방문자 띠·오행 캐릭터로 개인화한 버전과 일반 캐릭터 버전의 2p 이동률 비교 → 지표: 스토리 후킹 통과율 (1p → 다음 단계)
- 근거: 평점·만족도·신뢰 세입자 불만 다수 → 불만이 크게 줄었다고 전해짐(수치 미공개) (문제 재정의의 대표 예시로 인용됨) [출처](https://www.weforum.org/stories/2021/07/to-solve-big-issues-like-climate-change-we-need-to-reframe-our-problems/)

- 적용: 결제 전 두 페이지를 '통로'가 아니라 '무대'로: 1p 마지막 컷을 클리프행어(결정적 장면 직전)로 끝내 2p로 넘어가게 만든다
- 실험: 1p 마지막 컷을 클리프행어형과 일반 '다음' 버튼형으로 나눠 2p 이동률 비교 → 지표: 스토리 후킹 통과율 (1p → 다음 단계)

**아이들이 MRI를 무서워한다** (`mri`)
- 적용: 불안한 고민(이별·실직)을 겁주는 경고로 시작하지 말고 극복 서사로 시작한다: 1p 웹툰이 '나도 그랬는데 길이 보였다'는 흐름이면 불안한 방문자도 끝까지 본다
- 실험: 1p를 '극복 서사'형과 '경고'형으로 나눠 2p 이동률·이탈 지점 비교 → 지표: 스토리 후킹 통과율 (1p → 다음 단계)
- 근거: 평점·만족도·신뢰 다수 아동이 진정 후 검사 → 몰입한 아이들이 추가 진정 없이 검사받는 경우가 많아짐 (GE Adventure Series, 2008년 시범 도입 후 확대) [출처](https://www.dotmed.com/legal/print/story.html?nid=23433)

**안경테가 너무 비싸다** (`warby-parker`)
- 적용: '써 보고 산다'를 페이지 안으로: 1p 스토리에 방문자의 사주 특징 하나를 실제로 맞히는 장면을 넣어 '이거 진짜네'를 결제 전에 경험하게 한다
- 실험: 1p에 '성격 한 줄 맞히기' 장면을 넣은 버전과 일반 스토리 버전의 2p 이동률·구매 전환 비교 → 지표: 스토리 후킹 통과율 (1p → 다음 단계)

**오리지널 드라마에 큰돈을 걸어야 할까** (`house-of-cards`)

- 실험: 1p 스토리 유형 3종을 동시에 돌려 2p 이동률·구매 전환이 높은 유형 선택 → 지표: 스토리 후킹 통과율 (1p → 다음 단계)
- 근거: 구매자 수 두 시즌 제작비 약 1억 달러 → 공개 후 2년간 구독자 2,400만 명 늘어 5,700만 명 (원작·감독·배우 선호 데이터 기반) [출처](https://www.inc.com/associated-press/why-house-of-cards-is-the-foundation-of-netflixs-colossal-growth.html)

**친구가 없으면 소셜 앱이 재미없다** (`tiktok`)
- 적용: 첫 화면부터 바로 재미있게: 가입·긴 입력 없이 1p 스토리를 먼저 보여 주고, 생년월일 입력은 2p로 넘어가는 순간에 받는다

- 근거: 방문자·유입 월간 활성 사용자 6.89억 명 (2020.7) → 10억 명 (2021.9, +45%) (관심사 추천 피드 중심) [출처](https://techcrunch.com/2021/09/27/tiktok-reached-1-billion-monthly-active-users)

**명상 앱은 마니아용이다** (`calm`)
- 적용: 고객이 진짜 해결하려는 일에 톤을 맞춘다: 밤늦게 들어오는 방문자에게는 1p 스토리를 '불안을 달래는' 톤으로, 낮 방문자에게는 '결정을 돕는' 톤으로 보여 준다

**행사 기간 숙소 부족** (`airbnb`)
- 적용: 낯선 서비스를 믿게 만드는 장치를 2p에: 실제 구매자 후기, 적중 사례, 리포트를 쓴 캐릭터·작가 프로필을 마케팅 페이지에 둔다
- 실험: 2p에 실제 구매자 후기 3개 노출 A/B로 결제 페이지 이동률·환불률 비교 → 지표: 마케팅 후킹 통과율 (2p → 다음 단계)

**청소기 흡입력 저하** (`dyson`)
- 적용: 경쟁사가 주제별로 쪼개 파는 동안 '한 번 결제로 전체 결과 공개'가 우리 강점이다: 2p에서 포함 내용(연애·재물·건강·대운 등)을 전부 보여 주고 추가 결제 없음을 강조한다

**밀크셰이크 매출 늘리기** (`milkshake`)

- 실험: 유입 키워드(이직·연애·신년)별 맞춤 2p와 공통 2p의 결제 페이지 이동률 비교 → 지표: 마케팅 후킹 통과율 (2p → 다음 단계)

**음원 불법 다운로드** (`spotify`)
- 적용: 무료 맛보기를 깔때기로: 2p에서 실제 내 결과의 한 문단(예: 성격 요약)을 무료로 보여 주고 나머지 장을 결제로 연다. 맛보기 품질이 좋을수록 결제가 오른다
- 실험: 2p에 내 결과 한 문단 무료 공개 버전과 미공개 버전의 결제 페이지 이동률·구매 전환 비교 → 지표: 마케팅 후킹 통과율 (2p → 다음 단계)

**위치 체크인 앱이 복잡하다** (`instagram`)

- 실험: 2p를 단일 핵심 메시지형과 혜택 나열형으로 나눠 결제 페이지 이동률 비교 → 지표: 마케팅 후킹 통과율 (2p → 다음 단계)

**책을 사서 끝까지 안 읽는다** (`millie`)

- 실험: 2p에 포함 주제 목록 시각화 블록을 넣은 버전과 없는 버전의 결제 페이지 이동률 비교 → 지표: 마케팅 후킹 통과율 (2p → 다음 단계)

### 결제 페이지 (`checkout`) — 사례 35개

사주 서비스에서: 가격·옵션·결제 수단을 보고 결제를 끝낸다

살아남은 가설의 주요 장벽: 업계·고객 통념 38, 기술 변화 12, 시장·수요 변화 8

**비디오 대여 연체료 불만** (`netflix`)
- 적용: 압박·벌로 돈을 벌지 않는다: 가짜 카운트다운, 숨은 자동 결제 같은 장치는 당장 결제를 늘려도 환불·불신을 키운다. 가격과 포함 내용을 명확히 보여 준다
- 실험: 결제 페이지 카운트다운 타이머 제거 전후 결제 완료율과 환불률을 함께 비교 → 지표: 결제 완료율 (결제 페이지 → 결제 성공, 시도율 × 성공률)
- 근거: 구매자 수 건별 대여 + 연체료 모델 (1999년 9월 이전) → 구독자 100만 명 돌파 (2003) (1999년 12월 반납일·연체료 없는 정액제(Marquee) 출시 이후) [출처](https://www.fundinguniverse.com/company-histories/netflix-inc-history)

**신발은 신어 봐야 산다** (`zappos`)
- 적용: 위험을 회사가 진다: '결과가 마음에 안 들면 환불'을 결제 버튼 옆에 두면 결제 장벽이 낮아진다. 환불률을 가드레일로 함께 본다
- 실험: 결제 버튼 옆 환불 보장 문구 노출 A/B로 결제 완료율과 환불률 동시 측정 → 지표: 결제 완료율 (결제 페이지 → 결제 성공, 시도율 × 성공률)
- 근거: 재결제율 재구매 고객 비중 40%(2004) → 75% (반품이 4건 중 1건 이상인데도 매출총이익률 31% 유지) [출처](https://www.bu.edu/goglobal/a/goglobal_courses/tm648/spain/zappos.pdf)
- 근거: 객단가 (1회 결제 금액) 첫 구매 평균 111.98달러 → 재구매 평균 143.22달러 (2006년 4분기, 토니 셰이 발표) [출처](https://www.slideshare.net/slideshow/zappos-lessons-building-a-customerfocused-culture/256107)

**작은 가게는 카드 결제를 받을 수 없다** (`square`)

- 실험: 결제 수단 하나 추가 전후 결제 페이지 이탈률 비교 → 지표: 결제 완료율 (결제 페이지 → 결제 성공, 시도율 × 성공률)

**케냐에서 송금하기가 어렵다** (`mpesa`)

- 실험: 휴대폰 소액결제 추가 후 10대·50대 이상 결제 완료율 변화 측정 → 지표: 결제 완료율 (결제 페이지 → 결제 성공, 시도율 × 성공률)

**해외 송금 수수료가 숨어 있다** (`wise`)

- 실험: 결제 페이지에 '총액·포함 내용' 요약 박스 노출 A/B로 결제 완료율·환불률 비교 → 지표: 결제 완료율 (결제 페이지 → 결제 성공, 시도율 × 성공률)

**웹소설 유료 결제를 안 한다** (`kakaopage`)
- 적용: '무료 아니면 유료'의 이분법을 깬다: 결과의 일부(첫 장)는 결제 전에 보여 주고 전체는 결제로 연다. 시간 한정 첫 구매가를 쓸 때는 실제 조건으로만 쓴다
- 실험: 결제 페이지에 첫 장 미리보기를 붙인 버전과 없는 버전의 결제 완료율·환불률 비교 → 지표: 결제 완료율 (결제 페이지 → 결제 성공, 시도율 × 성공률)
- 근거: 결제 매출 2014년 1분기 → 2015년 1분기 매출 전년 동기 대비 4배, 일 매출 1억 원 (출시 2년, 기다리면 무료 도입 이후) [출처](https://www.kakaocorp.com/page/detail/7723)

**만화책은 휴대폰으로 보기 불편하다** (`naver-webtoon`)

- 실험: 2p 끝 '전체 결과 보기' 버튼 문구·위치 A/B로 결제 페이지 이동률 비교 → 지표: 마케팅 후킹 통과율 (2p → 다음 단계)

**신문 온라인 광고 수익이 줄어든다** (`nyt-paywall`)
- 적용: 얼마나 보여 주고 결제를 요구할지 정한다: 결제 전 무료 공개 분량이 너무 적으면 믿지 못하고, 너무 많으면 살 이유가 줄어든다
- 실험: 결제 전 무료 공개 분량(1문단 vs 3문단) A/B로 결제 완료율 비교 → 지표: 결제 완료율 (결제 페이지 → 결제 성공, 시도율 × 성공률)

**같은 엔진, 세 나라 세 가지 가격표** (`crack-pricing`)

- 실험: 질문권 1·5·10회의 회당 단가 차이를 크게(-36%) 두는 군과 작게(-15%)+첫 구매 할인 두는 군의 매출·회당 공헌이익 비교 → 지표: 주문 1건 공헌이익

### 질문권 Q&A (질문 1회 → 답변 1회) (`ask`) — 사례 57개

**질문 하나에 값을 매길 수 있을까** (`justanswer`)
- 적용: 질문권 1회 가격을 '이 질문 하나의 답' 기준으로 정하고, 답이 질문과 어긋나면 재답변 1회를 보장한다. 결제 화면에 고객이 쓴 질문 원문을 그대로 보여 주고 '이 질문에 답합니다'라고 적는다
- 실험: 같은 질문 화면에서 '30분 상담권'과 '질문 1건 답변'을 나눠 보여 주고 결제율 비교 → 지표: 질문권 구매율
- 근거: 결제 매출 2008년 이후 → 하루 약 1만 건 질문, 질문당 평균 약 30달러, 매출 연 123% 성장 (회사 공개 기준) [출처](https://vator.tv/n/27a3)

### 결과 열람·만족 (`consume`) — 사례 2개

사주 서비스에서: 구매 후 결과를 끝까지 읽고 만족한다 (환불·불만을 가르는 구간)

살아남은 가설의 주요 장벽: 문제·고객 정의 1, 기술 변화 1, 업계·고객 통념 1

**치과 대기 경험** (`dental`)
- 적용: 결제 직후 리포트가 생성되는 대기 시간을 비워 두지 않는다. 예상 완료 시간과 진행 단계(명식 계산 → 대운 분석 → 문장 작성)를 보여 주고, 완성되면 메시지로 알려 열람률을 지킨다
- 실험: 결제 후 생성 대기 화면에 예상 시간·진행 단계 표시 A/B로 결과 열람률·환불 문의 비교 → 지표: 구매 후 결과 열람·완독률

**공항 수하물 대기 불만** (`baggage`)
- 적용: 결제 후 기다리는 몇 초를 '서서 기다리는 시간'이 아니라 '걷는 시간'으로: 로딩 대신 분석 과정을 순서대로 보여 주는 연출로 체감 대기를 줄이고 열람 이탈을 막는다
- 실험: 결제 후 대기 화면을 분석 단계 연출형과 로딩 스피너형으로 나눠 결과 열람률·환불률 비교 → 지표: 구매 후 결과 열람·완독률
- 근거: 평점·만족도·신뢰 걷기 1분 + 서서 대기 7분, 불만 다수 → 걷는 시간이 늘자 불만이 거의 사라졌다고 전해짐 (공항·연도는 확인되지 않은 '전해지는 이야기') [출처](https://www.airtraveler.club/insider/airport-operations/houston-baggage-fix-cut-complaints-yet-nobody-can-verify-it-happened/)

### 재구매 (`repeat_pay`) — 사례 35개

사주 서비스에서: 시간이 지나 다시 산다 (신년운·다른 주제)

살아남은 가설의 주요 장벽: 업계·고객 통념 33, 기술 변화 14, 문제·고객 정의 7

- 실험: 생일 7일 전 재구매 제안 그룹과 무작위 시점 그룹의 재구매율 비교 → 지표: 재결제율

- 적용: 수요 검증 전에 고정비를 키우지 않는다: 새 주제 상품은 1p·2p 랜딩과 결제 버튼만 먼저 만들어 결제 의사부터 확인하고 리포트 생성은 그다음에 만든다
- 실험: 새 주제 상품을 랜딩 2페이지 + 사전 결제(예약)로 먼저 열어 결제 페이지 이동률 확인 후 제작 → 지표: 마케팅 후킹 통과율 (2p → 다음 단계)
- 근거: 건당 원가 창고 1곳 약 3,500만 달러 → 대부분 창고가 수용력의 3분의 1 수준으로 가동, 약 12억 달러 소진 후 2001년 파산 (닷컴 버블) [출처](https://d3.harvard.edu/platform-rctom/submission/webvans-demise-or-when-technology-fails-to-meet-operations)

**매출 15배, 손실도 커졌다: 종량형 AI 엔터의 원가 구조** (`wrtn-pnl`)
- 적용: 질문권 가격을 정하기 전에 답변 1건 원가(모델 호출 + PG·앱 수수료 + 검수)를 질문 종류별로 재고, 짧은 질문은 저가 모델로 보내는 라우팅을 시험한다
- 실험: 질문 분류로 짧은 질문은 저가 모델, 시기·궁합 질문은 상위 모델로 보내는 라우팅 적용 전후의 답변 1건 원가와 만족도 비교 → 지표: 답변 1건 원가 (LLM·검수)
- 근거: 결제 매출 2024년 매출 약 31억 원 → 2025년 매출 약 471억 원, 영업비용 약 1060억 원(광고 약 294억 원·지급수수료 약 611억 원), 영업손실 약 588억 원 (감사보고서 공시) [출처](https://www.koreatimes.co.kr/business/tech-science/20260414/wrtn-posts-15-fold-revenue-growth-in-1st-regulatory-filing)
- 근거: 재결제율 - → 결제 이용자 유지율 70% 이상, 일반 이용자 하루 평균 약 2시간 (회사 공개(로이터 인용)) [출처](https://www.woshipm.com/operate/6441577.html)
