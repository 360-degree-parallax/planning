# 크랙 · 캬라푸 · OOC 딥다이브 (질문권 Q&A 관점)

확인일 2026-11-27. 수치는 회사 발표·공시·보도 기준이며 각 줄에 출처를 단다. 사례 DB의 하위 사례 id를 괄호로 표시한다.

## 1. 한 장 요약
- 뤼튼은 무료 범용 AI로 사람을 모은 뒤, 서브컬처 팬이 오래 읽는 '이야기'에 종량형으로 돈을 받는 구조로 바꿨다.
- 돈을 낸 순간은 '더 많이'가 아니라 '더 잘'(상위 모델)이었다. 이용자가 먼저 요청한 품질 차이를 유료로 열었다 (crack-paywall).
- 국내 MAU는 줄었는데 매출은 늘었다. 결제자 밀도가 핵심이었다 (crack-spinoff).
- 같은 엔진을 일본 '캬라푸', 북미 'OOC'로 현지 브랜드화했고, 북미에서는 범주 이름을 '플레이 가능한 애니'로 바꿨다 (kyarapu, ooc-na).
- 매출이 커질수록 모델 호출비·수수료·광고비도 커져 아직 적자다. 단위 경제가 숙제다 (wrtn-pnl).
- 뤼튼은 운세 앱 '플롯'도 운영한다. 같은 엔진을 가진 회사가 운세에 들어온 신호다 (competitors.json `wrtn-plot`).

### 10-4. 메시지 1회 원가: 캐릭터챗 대 질문권 (가정 모델 단가 기준 예시)
가정 모델 단가: 저가 모델 입력 0.30달러·출력 1.20달러, 상위 모델 입력 3.00달러·출력 15.00달러(100만 토큰당). 실제 계약 단가가 아니다.

| 장면 | 입력 토큰 | 출력 토큰 | 저가 모델 | 상위 모델 |
|---|---|---|---|---|
| 캐릭터챗 장기 대화 한 턴(누적 맥락 2만 토큰) | 20,000 | 800 | 약 0.007달러 | 약 0.072달러 |
| 질문권 1회(명식 요약 + 리포트 장 + 지난 질문) | 4,000~7,000 | 600~1,500 | 약 0.002달러 | 약 0.044달러 |

- OOC 최상위 응답 판매가 약 0.13달러에서 앱 마켓 30%를 빼면 약 0.09달러가 남는다. 누적 맥락이 길어지는 상위 모델 대화는 이 가정에서 마진이 얇다. 그래서 OOC는 800토큰 초과 출력에 추가 차감을 붙이고, 기본 모델은 무료로 두되 상위 모드를 판다.
- 질문권은 대화가 이어지지 않아 맥락이 쌓이지 않는다. 같은 가정에서 질문 1회 모델 비용은 약 30원 수준이고, 원가의 대부분은 사람 검수·환불·결제 수수료와 획득 비용(광고)이다. 계산기: `python3 tools/unit_econ.py` (예시 `db/service/unit-econ.example.json`, 예시가 1회 3,900원 기준 공헌이익률 약 80%, 손익분기 판매가 약 215원).

### 10-5. 우리 질문권에 주는 시사점
1. 원가 구조가 크랙과 다르다: 질문권은 토큰 원가가 작고 광고비(CAC)가 크다. 가격은 원가가 아니라 가치(리포트와 이어지는 답, 명식 근거)로 정하고, 광고비 회수 기간(payback_days)을 핵심 지표로 둔다.
2. 웹사이트라 앱 마켓 수수료(15~30%)가 없다. 크랙이 웹 결제를 유도하는 이유가 우리에게는 기본 조건이다.
3. 할인은 첫 구매에만 크게, 묶음 할인은 작게(OOC·캬라푸 방식). 회당 공헌이익을 지킨다 (crack-pricing).
4. 길이·깊이로 차감을 나눈다: 기본 답 1회, 깊은 답 2회(OOC의 응답 등급·출력 길이 차감 방식).
5. 월 무제한은 하루 상한과 함께만: 플롯이 5월에 월 무제한을 붙였다. 무제한은 헤비 유저 원가와 자동 갱신 고지(dark-hidden-renewal) 위험이 있어 실험으로만 연다 (wrtn-plot).
